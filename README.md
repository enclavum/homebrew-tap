# enclavum/homebrew-tap

Homebrew tap for [enclavum](https://github.com/enclavum) apps.

## Install

```sh
brew tap enclavum/tap
brew trust enclavum/tap  # required on recent Homebrew

brew install otaku  # otaku (CLI)
```

## Formulae

- **[otaku](https://github.com/enclavum/otaku)**: LLM frontend for roleplay and creative writing
